# LG_NewUi（PHP 原版）

来自 [me.cq.je/love.zip](https://me.cq.je/love.zip) 的 **PHP LGNewUI** 情侣小站源码。

| 路径 | 说明 |
|------|------|
| `love.zip` | 原始压缩包 |
| `website/` | 网页端（`index.php`、后台 `admin/` 等） |
| `wxapp/` | 微信小程序端 |
| `DEPLOYMENT.md` | 部署说明 |

## 部署

1. 将 `website/` 上传到站点根目录（PHP 8.2–8.5 + MySQL）
2. 在 `website/` 执行：`composer install`
3. 浏览器打开 `/install/` 完成安装
4. 详见 `DEPLOYMENT.md`
