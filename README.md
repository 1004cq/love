# LG_NewUi（PHP 原版 · 完整解压）

来自 [me.cq.je/love.zip](https://me.cq.je/love.zip) 的 **PHP LGNewUI**，已在仓库内**完整解压**（含 `website/vendor/`）。

| 路径 | 说明 |
|------|------|
| `love.zip` | 原始压缩包 |
| `website/` | 网页端（完整，含 Composer `vendor/`） |
| `wxapp/` | 微信小程序端 |
| `DEPLOYMENT.md` | 部署说明 |

## 部署

1. 将 `website/` 上传到站点根目录（PHP 8.2–8.5 + MySQL）
2. 浏览器打开 `/install/` 完成安装
3. 详见 `DEPLOYMENT.md`
